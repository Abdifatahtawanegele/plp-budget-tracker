# My Budget Tracker - Week 1

## What I Built
A simple static Budget Tracker foundation with semantic HTML structure.

## What Each Part Does
**index.html:**
- Header with title and description
- Add Expense Section with inputs for name, amount, category
- Your Expenses placeholder section

**style.css:**
- Basic styling with colors, padding, border-radius
- Clean layout with container max-width

## How to Run
Open index.html in browser. Right-click > Inspect to view structure.

## Screenshot
Shows Add New Expense form and Your Expenses placeholder with DevTools open.
